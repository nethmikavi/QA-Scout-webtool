QA Checklist Reference

Standards verified during every single-pass QA Scout scan:

🔗 Links Module: Crawls same-domain anchor tags, checks HTTP status codes, and detects broken links or redirect loops.
🛡️ Security Headers: Audits HTTPS enforcement, HSTS, Content Security Policy (CSP), and X-Frame-Options headers.
📈 SEO Analysis: Validates presence of title tags, meta descriptions, canonical links, and Open Graph tags.
♿ Accessibility (A11y): Flags missing image alt attributes, unlabelled form inputs, and heading structure issues.

API Documentation

Integrate QA Scout automated audits programmatically into your CI/CD pipeline.

Endpoint: POST /api/scan

Sends a target URL to the Node.js backend scanner and returns a structured JSON report.

curl -X POST http://localhost:3000/api/scan \
  -H "Content-Type: application/json" \
  -d '{"url": "https://example.com"}'

Free & Open Source

QA Scout is built for developers, QA interns, and small businesses with zero paywalls.

Designed as a lightweight, modular quality engineering utility utilizing:

  • Backend: Node.js, Express, Cheerio, Helmet.js
  • Storage: SQLite for local report caching
  • Frontend: Modern responsive dark SaaS grid layout
